AI and external services

Every service this app talks to that is not part of its own source code — what it is for, what it costs, and what happens when it is unavailable.

The rule is simple: the games work without any outside service. The free question bank, the rule-based arena brain and the scripted commentary are the normal path. A paid model is an extra the player asks for, metered per player per day, and when it is missing or over budget the free path answers instead. No game has a feature that only exists if a cloud model is reachable.

How to read the cost column. "Free" means no money leaves the account. "Optional" means money can leave the account, but only if a signed-in player turns it on. "None" means the service is never called. Nothing on this page can spend money without a player having asked for it first — except the quiz bank filler, whose paid top-up switch is off by default src/PoMiniGames.API/appsettings.json:42.

The cost boundary

A hard daily ceiling per player

Every identity may spend 250,000 tokens per UTC day across the whole AI surface. The value is declared in code and repeated in configuration src/PoMiniGames.API/AI/AiTokenBudget.cs:14 src/PoMiniGames.API/appsettings.json:47.

The message says when it resets

The exception carries what was spent, the limit and the reset time, so a handler can answer with a reset instead of pretending the model is broken src/PoMiniGames.API/AI/BudgetedChatClient.cs:99.

Rate limits on top

The safety boundary in one paragraph

Nothing in this application can spend money on its own. A Foundry call needs the request to have resolved to FreshAi or to an ambiguous judge case; that needs a signed-in player and a configuration flag; that player has a daily token ceiling; and every call passes a budget check before it leaves the server. Jev needs a second opt-in on top: the server-side brain setting, a configured key, and the player's own choice in Settings. The only background process that can spend is the quiz bank filler, and its paid top-up switch is off by default src/PoMiniGames.API/appsettings.json:42.
