PoMiniGames — Executive & Plain-English Overview

In plain English: PoMiniGames is a single website hosting 14 instant-play browser mini-games. Your browser runs the game graphics, sound, and computer opponents locally, while one .NET 10 server handles player sign-in, live multiplayer rooms, and saving high scores.

Built as a single-origin platform, the backend serves the Blazor WebAssembly frontend directly on port 5080 so there is no cross-site friction in production. If your internet drops, finished scores are safely parked in your browser and sent automatically when you reconnect.
