Security & Access Control Report

In plain English: Every player gets a signed visitor badge (Microsoft Entra JWT in production, or a local-only cookie in development), and every write request is checked at four gates: Identity, Rate Limit, Anti-Forgery (CSRF), and Score Plausibility.
