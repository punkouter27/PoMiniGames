User workflows

What people do on the site

Six journeys cover almost everything: arrive and pick a game, play and post a score, play someone online, check the boards, look after your own data, and (for the owner) check that the site is healthy.

1. Arrive and start a game

GoalGet from a link to playing in a few seconds, with nothing to sign up for.
  1. Open the siteThe browser downloads the app once; later visits start from the cache.
  2. Type three initialsA small prompt asks for initials the first time. A random player id is made and kept in the browser.
  3. Pick a game cardThe card smoothly morphs into the game's title, with no page reload.
  4. Press OK on the start cardOne button, plus a map picker in games with several maps.
  5. Play, then go backThe end card has one button: "Back to main menu".

2. Play solo and post a score

GoalFinish a round and see the score on the public board, even if the Wi-Fi drops at the wrong moment.
  1. Ticket at the startOpening a game quietly asks the server for a signed "play session" ticket.
  2. Play the roundEverything runs in the browser.
  3. Save locally firstYour personal stats and achievements are written on the device.
  4. Send the scoreThe score goes to the server with your id, initials, the ticket and an anti-forgery token.
  5. Server checks itIs the number possible at all? Could it have been earned in the time the ticket has been open?
  6. Saved, or parkedIf the server cannot be reached, the score waits in the browser and is sent again on reconnect.

3. Play someone online

GoalFind an opponent without swapping codes: each game has exactly one shared lobby.
  1. Choose OnlineYou join the game's single lobby. The first person in hosts.
  2. Ready upWhen both seats are filled, the host starts the match.
  3. Live matchEvery move goes to the server, which checks it and relays it to the other player.
  4. Result recordedThe head-to-head result is saved to your match history.

5. Look after my own data

GoalDownload everything the site holds under your player id, or erase it. You can only ever reach your own id.
  1. Open settings → PlayerChange initials, see stats, or manage data.
  2. ExportOne file with every board row under your id.
  3. EraseRemoves those rows. Limited to five tries a minute because each one scans every table.
  4. Invite a past opponentOptional: allow notifications, then send a push invite to someone you have played.
