PoMiniGames, explained

Fourteen browser games on one website. You open a link, type three initials, and play: alone, side by side on one keyboard, or online against someone else. There is no account and no password.

What it is for

In one sentenceAn arcade you carry in a browser tab: quick games, a high-score board per game, and a shared lobby for playing a friend online.

The site is a single web app hosted on Azure. It remembers each player by a random id kept in their own browser plus the three initials they typed, the same way an arcade cabinet remembers "AAA" on its score table. Scores go to public leaderboards; stats and achievements stay on the device.

Hosting
One Azure App Service (F1, Windows, .NET 10) serves both the game client and its API from one address.
Data
Azure Table Storage for scores and ratings, Blob Storage for saved islands and key material.
Realtime
SignalR "hubs" carry live online matches and lobbies, held in server memory.
